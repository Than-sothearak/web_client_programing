Welcome

Welcome to my learning website. This website was created as part of an HTML5 practice project. Students will learn how to build web pages using proper HTML structure, semantic elements, and different types of content.

Through this project, students will practice creating headings, paragraphs, lists, images, links, tables, and forms. The goal is to understand how webpages are structured and how different elements work together.

Technologies I Learn

In this course, students will learn the basic technologies used to build modern websites. Each technology has its own purpose in web development.

    HTML5

    • Creating webpage structure
    • Using headings and paragraphs
    • Creating lists and links
    • Building forms

    CSS

    • Styling webpages
    • Changing colors and fonts
    • Creating layouts
    • Responsive design

    JavaScript

    • Making websites interactive
    • Handling user actions
    • Updating webpage content dynamically

Learning Steps

Students will follow several steps when learning web development. Each step builds on the previous one.

  1. HTML Basics

    • HTML document structure
    • Headings and paragraphs
    • Lists and nested lists
    • Links and navigation

  2. Intermediate HTML

    • Images and media
    • Tables
    • Forms

  3. CSS Styling

    • Colors and typography
    • Spacing and layout
    • Flexbox and responsive design

  4. JavaScript Basics

    • Variables
    • Functions
    • Events
