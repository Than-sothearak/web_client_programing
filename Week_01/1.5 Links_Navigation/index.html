Welcome to my learning website. This project helps students learn HTML structure and how to create webpages using semantic HTML elements. Students will also practice building webpages and understanding basic web development concepts.

In this website you will learn how to use headings, paragraphs, lists, links, images, and forms.
You will also learn how to organize content and structure a webpage properly.
Practice coding every day to improve your skills.

Technologies I Learn

Students will learn the basics of HTML, CSS styling, and responsive web design. These technologies are essential for building modern websites.
